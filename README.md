# 🪖 Calculadora de Alistamento Militar (`alistamento-mil2.py`)

Programa em Python desenvolvido para verificar a situação de alistamento militar obrigatório com base na data de nascimento informada pelo usuário.

## ⚙️ Funcionalidades
- Lê a data de nascimento completa no formato `DD/MM/AAAA`.
- Calcula a idade atual exata considerando o dia, mês e ano correntes (`datetime`).
- Informa se o usuário:
  - Ainda vai se alistar e quanto tempo falta para completar 18 anos.
  - Está no ano exato de realizar o alistamento obrigatório.
  - Já passou do prazo de alistamento e quanto tempo se passou desde os 18 anos.

## 🛠️ Tecnologias Utilizadas
- **Python 3** (módulo nativo `datetime`)
